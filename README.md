## 🚀 What I'm building

* **[MyKK Dashboard](https://start.mykk.us)** — A single-file browser start page with 30+ widgets (weather, stocks, RSS, calendar, bookmarks, and more). Vanilla JS, no frameworks. Pro tier via Chrome Extension + Stripe subscriptions. Cloud sync with Firebase.
  Repos: [mykk.us-dashboard](https://github.com/MichalAFerber/mykk.us-dashboard) · [mykk.us](https://github.com/MichalAFerber/mykk.us)

* **[De-Google.US](https://de-google.us)** — Privacy education site promoting alternatives to Google services. Side-by-side comparisons, migration guides, and product recommendations. Built with Jekyll + Cloudflare Pages.
  Repo: [degoog.us](https://github.com/MichalAFerber/degoog.us)

* **[IP Cow](https://ipcow.com)** — Free IP lookup tools (IPv4/IPv6, CLI tools, domain parking). A small ecosystem of five repos powering the service.
  Repos: [ipcow](https://github.com/MichalAFerber/ipcow) · [ipcow-checkip](https://github.com/MichalAFerber/ipcow-checkip) · [ipcow-checkipv6](https://github.com/MichalAFerber/ipcow-checkipv6)

* **[Unbound Homelab](https://github.com/MichalAFerber/unbound-homelab)** — Production-ready redundant DNS infrastructure for home labs. DNSSEC, health monitoring, automated config management on Raspberry Pi.
