## 🚀 What I'm building

* **[tgwab-web](https://github.com/MichalAFerber/tgwab-web)** — pnpm + Astro 5 monorepo powering five sites (hub, blog, dev portfolio, family, ham radio) from one shared design system (`@tgwab/design-tokens` + `@tgwab/ui`). Cloudflare Pages, no Google Fonts.

* **[MyKK Dashboard](https://start.mykk.us)** — A single-file browser start page with 10+ widgets (weather, stocks, RSS, calendar, bookmarks, ambient sounds, more). Vanilla JS, zero deps. Pro tier via Chrome Extension + Stripe.
  Repos: [mykk.us-dashboard](https://github.com/MichalAFerber/mykk.us-dashboard) · [mykk.us](https://github.com/MichalAFerber/mykk.us) · [mykk.us-extension](https://github.com/MichalAFerber/mykk.us-extension)

* **[ResizeWizard](https://resizewizard.app)** — Chrome extension for quick, anchored browser-window resizing. Live on the Chrome Web Store. Free + Pro tiers.
  Repos: [resizewizard-extension](https://github.com/MichalAFerber/resizewizard-extension) · [resizewizard-website](https://github.com/MichalAFerber/resizewizard-website) · [resizewizard-cf-worker](https://github.com/MichalAFerber/resizewizard-cf-worker)

* **[IP Cow](https://ipcow.com)** — Free IP lookup tools running since 2005 (IPv4/IPv6, CLI tools, domain parking). A small ecosystem of six repos powering the service.
  Repos: [ipcow](https://github.com/MichalAFerber/ipcow) · [ipcow-checkip](https://github.com/MichalAFerber/ipcow-checkip) · [ipcow-checkipv6](https://github.com/MichalAFerber/ipcow-checkipv6) · [ipcow-domain-parking](https://github.com/MichalAFerber/ipcow-domain-parking) · [ipcow-assets](https://github.com/MichalAFerber/ipcow-assets)

* **[Unbound Homelab](https://github.com/MichalAFerber/unbound-homelab)** — Production-ready redundant DNS infrastructure for home labs. DNSSEC, health monitoring, automated config management on Raspberry Pi.
